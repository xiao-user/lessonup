# 教育专业能力验证

## 三种独立的证据

| 验证层 | 能证明什么 | 不能证明什么 |
| --- | --- | --- |
| 工程契约与浏览器测试 | 作用域、版本、交付、取消、恢复、可编辑性与指定设备条件下的性能 | 学科教学判断正确、学生学习改善 |
| 模型评分与真实工具冒烟测试 | 给定案例的原生工具调用与初步质量筛查 | 独立专家共识、国家级专业水平 |
| 人工专业评审与真实课堂追踪 | 专家对具体成果的判断，以及特定条件下实际学习表现 | 不经研究设计即可认定方法的因果效应、推广到全部群体 |

本仓库提供评审工具，不提供虚构的专家意见。评审者身份、资历与独立性由评审组织者核验；脚本仅校验填写完整性、版本、重复评分、分歧和门槛。

## 评审材料与操作

运行 `npm run eval:agent` 时，结果同时保存当时的教师请求、规范内容、教学依据、反馈与助手可见成果。`npm run eval:learning:smoke` 的隔离合成案例也提供同一评审材料结构，可直接导出；其教学方案和复测建议按教师可读内容呈现，保留合成数据标签。输出在系统暂存目录，不进入版本库。历史结果若缺少 `reviewMaterial`，必须重新获取对应快照，不能凭当前文档补成过去的证据。

导出已有评测结果到一个**不存在的新目录**：

```bash
npm run eval:professional -- export /tmp/agent-results.json /tmp/lessonup-review-round1
```

- `packet.json`：随机编号并随机排序的任务、原始材料与成果；无自动评分、模型身份、耗时或原案例编号。
- `rubric.json`：六个维度各自的0—3级行为锚点，以及材料指纹。
- `rating-template.json`：每份成果的空评分模板，`null` 是尚未评分，不是零分。
- `coordinator-key.json`：组织者保留的案例编号映射，文件权限0600。不得与盲评包一起交给评审者。

盲化限于元数据；保留成果原文，不为掩盖表达风格而改写。至少两位独立评审者分别检查学科与学段匹配性、实际课时条件和给定资料，完成评分及可定位的依据后各自保存文件。此工具不会联系或自动指定评审者。

```bash
npm run eval:professional -- summarize /tmp/lessonup-review-round1/packet.json /tmp/round1-summary.json /tmp/reviewer-a.json /tmp/reviewer-b.json
```

空评审集合输出 `pending` 并以非零状态结束；重复评审者、未知样本、材料指纹不符、缺失维度和模型署名均不能通过。任何虚构证据、因果夸大、关键学科错误或排除性安排直接不通过。任一维度相差至少两级，标为待仲裁，不用平均分抹平分歧。评审组织者应保留原始独立评分，开展复核后使用新的评审轮次，不能静默覆盖。

当前项目筛查门槛为：至少两人完整评分、每项至少2分、总体平均至少2.5分、无严重问题及大分歧。该阈值是待校准的项目规则，不是教育部、WWC或国家级专家认证标准。`passed` 仅表示本轮样本通过本项目规则。

## 案例覆盖与真实课堂验证

不能只选择成功的语文备课案例。评审轮次应覆盖不同学段及数学、语言、科学、人文、跨学科实践，保留失败与无须修改案例，并包含：

| 情境 | 必须检查的专业判断 |
| --- | --- |
| 学生负数比较结论正确、解释不足 | 区分概念表征、记忆规则和表达负担；检查能否独立用新例解释 |
| 文本存在多种有证据的解读 | 不把唯一标准话术当作理解；评价证据质量及解释联系 |
| 实验同时改变多个条件 | 不将观察差异归因为单一变量；提出可区分解释的实验 |
| 跨学科调查或建模 | 核心问题决定学科联系；核对单位、抽样与数据质量，不强行拼接活动 |
| 学生表达或参与方式不同 | 保留共同目标，调整表达路径与支架，不据一次表现贴固定标签 |
| 资料冲突、反馈缺失、干预失败 | 保留反例、识别缺口，允许不改或无法判断，提出下一条最有价值的证据 |

课堂追踪分别记录基线、实际实施、即时表现、无提示的新任务和适当延迟后的表现，同时记录教师工作量、支架与取证变化。不同任务难度、不同群体或提示变化会限制可比性。提出方案、采用、课上热闹或同题即时进步均不能直接当作独立掌握与迁移。

这些检查与 WWC 指南中对间隔安排、表征联系、练习与解释性问题的建议相关；该指南分别标明证据强度，不能将所有策略一概称为强证据，也不能据通用策略推断本班效果。[IES/WWC：Organizing Instruction and Study to Improve Student Learning](https://ies.ed.gov/ncee/wwc/PracticeGuide/1)。
