# 文档画布工作区 — 2026-11-03

A4 教案与学期框架统一为左侧文档画布、右侧独立助手面板。保留既有文档、教学规划、审批和书本往返动效。

- 顶部保留返回、文档身份及同步状态；目录按需展开，编辑与手形拖动放入左侧浮动工具栏。
- 两处共用画布控制：25–200% 缩放、适应宽度、鼠标或空格拖动、Ctrl/Command + 滚轮缩放。指针与滚轮事件按帧合并；滚动和光标使用浏览器原生坐标，不逐帧更新业务状态。
- 缩放只改变显示比例。A4 分页仍依据原始纸张尺寸；打印恢复原始 A4。学期框架的单元与课时顺序、版本和保存方式保留。
- 助手可收起和展开，手机使用抽屉。框架抽屉独立拥有定位，避免继承教案隐藏侧栏的姿态而出现空白。
