# 03 验证协议：在没有真实教师的情况下如何先开始

真实教师访谈与 8–12 位教师的课堂 pilot 暂不可用。本协议把“现在能做的”和“必须等教师才能做的”严格分开，避免用代理证据冒充课堂证据。

## 1. 证据阶梯

| 层级 | 回答的问题 | 方法 | 现在能否做 | 不能证明 |
| --- | --- | --- | --- | --- |
| L0 工程正确 | 系统按合同工作吗 | 单测、浏览器契约、工具契约、回放 | 能 | 专业质量、学习效果 |
| L1 专业质量（代理） | 建议是否专业、可执行 | 内部盲评 + rubric + 一致性 | 能（标注代理） | 外部专家共识 |
| L1' 专业质量（外部） | 外部专家是否认可 | ≥2 名独立外部专家、盲评、仲裁 | 暂不能 | 学生学习改善 |
| L2 决策质量 | 是否推动更好的判断 | 同案例对照、盲评、决策时间 | 能做代理版 | 课堂实施与结果 |
| L3 实施保真 | 教师是否按方案实施 | 课堂观察、录像编码、fidelity | 暂不能 | 学习结果 |
| L4 学习结果 | 学生是否更好 | 前后测 + 保持 + 迁移、多层模型 | 暂不能 | 大规模推广 |
| L5 规模化 | 是否可复制 | 多校复现、外部审计 | 暂不能 | 无 |

## 2. 当前可执行的验证（Phase 0–2）

### 2.1 内部盲评（专家代理）

- 材料：现有评测案例（`evals/cases.jsonl`）、真实运行结果、决策简报样本。
- 评审：2–3 名具备学科/教研背景的内部评审者；**不得在报告中称为外部专家或国家级评审**。
- 流程：使用 `npm run eval:professional -- export` 生成去标识、随机排序的盲评包；双人独立评分；`summarize` 统计覆盖、严重问题、大分歧与一致性。
- 报告必须包含：评审者背景与独立性说明、评分一致性（κ 或 Krippendorff α）、分歧项、仲裁记录、严重错误清单。
- 通过门槛先沿用项目现有规则，但明确它是**待校准的项目规则**，不是外部认证。

### 2.2 决策质量代理对照

目的：检验“决策简报”是否比“材料生成”更能帮助教师做判断；不声称课堂效果。

- 样本：20–30 个课时案例（现有评测集 + 现有学习证据覆盖的课时）；不足时用明确标注的合成案例补足，但合成案例只用于流程与可用性，不进入专业质量结论。
- 对照：
  - A：当前 Agent 输出（文档提案/建议）。
  - B：同一证据条件下的决策简报（决策对象 + 选项 + 证据 + 反例 + 不确定性 + 下一步证据）。
- 盲化：去除模型、耗时、来源标签；随机顺序；同一评审者不看同一案例的两个版本，或采用交叉设计。
- 维度（0–3 分，附锚例）：
  1. 决策是否明确、可执行；
  2. 证据是否可定位、与判断相关；
  3. 是否比较了替代方案与反例；
  4. 不确定性与适用条件是否诚实；
  5. 预期信号与证伪条件是否可观察；
  6. 教师理解与使用成本（主观负荷）。
- 统计：描述统计 + 配对比较（Wilcoxon 符号秩或混合模型）；报告效应量与不确定性区间；同时报告一致性。
- 结论边界：只能说明“在内部代理评审中，B 是否更清晰/更可检查”，不能说明学生更好。

### 2.3 性能与可用性验证

- 使用真实设备/网络（至少 1 台低端 Android/Chromebook、1 台教师常用笔记本）跑 Playwright trace、Lighthouse、WebPageTest。
- 指标：INP p75、长任务、首字延迟（TTFT）p50/p95、工具往返、取消响应、错误率。
- 单机数字只用于纵向比较，不作为对外承诺。

### 2.4 预注册（在收集数据前完成）

写清：

- 假设与方向（H1–H4）；
- 主要/次要指标与测量工具；
- 样本与纳入/排除标准；
- 对照/盲法/随机化；
- 分析计划（模型、缺失值、敏感性分析）；
- 停止规则与负结果处理；
- 预注册时间戳与版本。

## 3. 真实教师 pilot 预案（教师资源到位后启动）

### 3.1 设计

- 对象：8–12 位教师，一个学科、一个学段、一个单元；4–6 周。
- 设计优先级：
  1. 阶梯式楔形（stepped-wedge）：所有教师最终使用，按时间分批，适合小样本；
  2. 匹配对照：按教龄、班级学情、课时进度匹配；
  3. 单组前后测仅作探索，不作因果结论。
- 预注册；随机化在教师/班级层；分析考虑嵌套结构。

### 3.2 测量

| 维度 | 工具/指标 |
| --- | --- |
| 决策质量 | 盲评 rubric（教师确认的决策记录 + 理由 + 证据） |
| 教师成本 | 每周备课时间日志、time-to-decision、返工次数、负荷量表 |
| 实施保真 | 课堂观察/录像编码、fidelity checklist、剂量（分钟/次数） |
| 学生结果 | 前测、后测、延迟保持、无提示迁移任务；题目难度/区分度 |
| 过程 | 决策采纳/拒绝理由、证据查看、保留现稿、后续调整 |
| 安全性 | 错误引用、越权、隐私事件、严重学科错误 |

### 3.3 分析

- 多层模型（学生嵌套班级/教师）；效应量（Hedges' g）与 95% CI。
- 缺失数据：多重插补或明确模型；敏感性分析。
- 实施保真作为解释变量，不把偏离简单归因于方案。
- 负结果、无效结果与反例必须报告。

### 3.4 伦理与合规

- 学校授权、教师知情同意、学生/家长告知（按学校与法规要求）。
- 数据最小化、脱敏、访问审计、保存期限；学生原始作品存 R2 私有对象。
- pilot 前完成数据保护影响评估与撤回机制。

## 4. 报告模板

每轮验证报告包含：

1. 问题与假设（预注册版本）；
2. 样本与实施（含偏离）；
3. 主要/次要结果（效应量、CI、缺失）；
4. 一致性与严重问题；
5. 反例与负结果；
6. 局限（代理/外部、样本、实施、测量）；
7. 结论的适用范围与下一步；
8. 可复现材料位置。

## 5. 停止规则

- 内部盲评出现严重学科错误或大分歧未解决：停止进入 Phase 1，先修 rubric/模型。
- 决策质量代理对照无实质差异：回到问题定义，不扩功能。
- 真实 pilot 中学生结果无改善或教师成本上升：停止或缩范围，公开报告。
- 合规未完成：不得采集学生数据。
