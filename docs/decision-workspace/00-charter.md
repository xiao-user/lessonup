# 00 章程：从材料交付到教学决策

## 根本目标

让教师在真实课堂里做出更好的教学决策，从而改善学生的理解、保持与迁移，同时降低教师的备课与判断负担。教案、演示、学习记录是决策的载体，不是效果的证明。

## 产品命题（可证伪）

当前产品已经能更快产出可审批的教案，但尚未证明“决策更好”。本阶段提出四条可证伪假设：

- **H1 决策质量**：在相同课时与证据条件下，使用决策工作台的教师，其目标取舍、任务序列、支架与评价证据的质量高于仅使用材料生成流程的教师。
- **H2 教师成本**：决策工作台减少教师查资料、返工与解释成本；节省时间为测量值，不是宣称。
- **H3 课堂实施**：决策记录能提高实施保真度与后续调整的针对性。
- **H4 学习结果**：在真实课堂 pilot 中，学生独立、保持与迁移表现相对基线改善；允许负结果，不能由前后测直接推定因果。

任何一条不成立，都应停止或改写产品方向，而不是用更多功能覆盖。

## 范围

### Phase 0（当前）：审计与协议

- 审计现有 Agent 流、工具面、数据、评测与性能，形成可核查的失败模式。
- 定义决策对象、证据卡、决策 diff、生命周期与数据模型草案。
- 定义证据阶梯、替代验证方案与真实教师 pilot 预案。
- 定义埋点、指标与性能 SLO。
- 不迁移数据库、不改生产行为、不宣称专业或学习效果。

### Phase 1：一个垂直切片

- 选择一个学科、一个学段、一个单元/课时。
- 实现决策记录的只读展示与最小写入（提案 → 教师确认），证据卡可追溯到原始材料。
- Agent 能提出“决策候选”，必须附证据、替代解释、不确定性与下一步证据；允许“不改”。

### Phase 2：内部代理验证

- 使用现有评测集与内部盲评工具，比较“材料生成”与“决策简报”的决策清晰度、证据质量、可执行性与不确定性表达。
- 报告内部一致性（κ/α）与严重问题；标注为内部专家代理，不冒充外部专家。
- 预注册真实教师 pilot 的方案与停止规则。

### Phase 3：真实课堂 pilot（教师资源到位后）

- 8–12 位教师、4–6 周、一个单元；对照或阶梯设计；真实学生作品与延迟/迁移测量。
- 独立专家盲评与外部审计；负结果照实报告。

## 约束

1. 真实教师访谈与课堂 pilot 暂不可用；当前所有专业判断只能由内部评审代理，并明确标注局限。
2. 不编造课标引用、学生表现、课堂观察或效果数据；不把模型生成内容当作证据。
3. 不把采用率、生成速度、界面流畅度当作教学效果。
4. 学生数据受《个人信息保护法》与《未成年人网络保护条例》约束；Phase 0 不采集新的学生个人数据。
5. 沿用既有技术边界：一个 Pi 协调器、一个配置模型、D1 为事实源、R2 私有对象、审批与版本合同不变。

## 非目标

- 不做多学科同时铺开；不增加新 Skill 或第二个 harness。
- 不以“更长的教案、更多功能、更多仪表盘”作为质量。
- 不在 Phase 0 迁移数据库或上线决策记录。
- 不宣称国家级专家水平、学习效果提升或因果结论。

## Phase 0 退出标准

- 现状审计能回答：有什么、主要功能、接入后变化、对教师作用；每条附代码/数据/测量证据。
- Agent 流验证列出可复现的失败模式与证据缺口，而不是泛泛评价。
- 决策对象与证据卡覆盖至少 6 类真实教学判断，并有 JSON schema 与状态机。
- 验证协议明确：现在能证明什么、不能证明什么、教师到位后如何开始。
- 指标与 SLO 有定义、测量方法、预算与隐私边界。
- 文档通过产品/工程/（内部）教学评审；未通过项进入下一轮修订。

## 治理与决策权

- 教师保留最终决定权；系统只提出候选、证据与不确定性。
- 任何“采用”不等于“有效”；任何“实施”不等于“保真”。
- 数据与结论均可追溯：来源、版本、适用条件、反例、失效时间。
- 对外表述必须与证据层级一致；内部代理证据不得包装成外部专家结论。

## 风险与假设

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 没有真实教师，决策模型可能脱离实际 | 模型好看但不可用 | 用现有课堂证据、评语、反馈记录与教研材料校准；明确待验证项 |
| 决策记录增加教师负担 | 使用率低、返工增加 | 默认最小字段；先只读/候选；用时间动作测量决定是否保留 |
| 证据卡变成新的“文档堆” | 信息过载 | 只保留影响当前决策的证据；冲突显示而非取平均 |
| 内部评审自我确认 | 高估质量 | 盲化、双人、一致性系数、预注册、外部审计 |
| 性能预算与模型延迟混为一谈 | 错误承诺 | UI 与模型分列 SLO；真实设备/网络测量；报告 p50/p95 |
| 学生数据合规 | 法律与伦理风险 | Phase 0 不新增采集；pilot 前完成授权、脱敏、审计与保存期限 |
