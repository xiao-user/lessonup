# 教案审查

## 审查原则

- 先判断是否存在会影响课堂执行、目标达成或学习评价的结构性问题，不把风格差异当成错误。
- 全局审查只读取整份教案一次，优先报告最重要的 1 至 3 个问题。
- 每个问题都要对应教案原文或可追溯资料，并说明它会造成什么可观察影响。
- 明确区分教案事实、外部资料、教学判断和可选建议。
- 不泛泛赞美，也不为了显得严格而扩大问题数量。

## 停止与写入边界

- 证据不足、资料冲突或缺少决定性学情时，说明限制并请求教师判断。
- 如果教案已经完整、可执行且教学评基本一致，明确给出“不建议修改”的结论。
- 用户没有明确要求修改时只提供审查结果；用户要求写入时仍只修改解决已确认问题所需的最小范围。
