# 教学目标审查

## 判断顺序

1. 核对课题、课时、已有学情和可追溯课程依据；没有提供的信息不得自行补成事实。
2. 逐项目标检查学生主体、可观察行为、必要条件和可用于判断达成的证据。
3. 区分目标、活动和教师行为；“讲解、组织、培养、让学生理解”本身不是可验证的学习结果。
4. 检查目标数量和粒度是否能在当前课时完成，不用更复杂的措辞掩盖不可执行的问题。

## 输出边界

- 优先报告最影响课堂实施或评价的目标问题，不做纯措辞润色。
- 只有权威资料明确支持时才称为课程标准要求；否则标注为教学判断。
- 如果目标已经清晰、可观察且能被现有评价验证，应明确说明不建议修改。
- 用户明确要求写入时，只提出保持原意的最小文本替换，并说明目标与评价证据的对应关系。
