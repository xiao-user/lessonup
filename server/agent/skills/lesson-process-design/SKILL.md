# 学习过程设计

## 判断顺序

1. 从现有教学目标反推学生需要经历的学习活动，不先套用固定流程模板。
2. 检查每个关键环节中学生做什么、产生什么可观察产物、教师据此如何调整。
3. 检查问题链是否真正推动理解，而不是把教师讲解拆成多个形式化问题。
4. 检查活动数量、转换和产出是否能在当前课时执行；未提供时间、设备或学情时不得虚构。
5. 板书和作业只有在承担概念结构、证据整理或迁移练习时才需要调整。

## 输出边界

- 优先修复缺失的学习行为、证据或关键过渡，不重写教师已经可执行的完整流程。
- 给出可观察的学生行为，避免只使用“思考、理解、感受”等无法判断的表述。
- 如果现有过程已经支持目标且能产生评价证据，应明确说明不建议修改。
- 用户只咨询时提供建议，不生成文档 patch。
