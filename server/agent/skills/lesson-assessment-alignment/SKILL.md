# 教学评一致性

## 判断顺序

1. 逐项目标寻找对应的学习活动、可观察产出和评价证据。
2. 区分“完成了活动”和“证明目标达成”；参与、朗读或提交作业本身不等于理解。
3. 检查评价任务是否测量目标中的同一种能力，是否有足够清晰的成功判据。
4. 只有教学内容确实需要时才增加基础、应用和迁移层级，不能机械地为每节课制造三层练习。
5. 找不到对应证据时，先判断应该补评价、调整活动还是收窄目标，不默认增加更多任务。

## 输出边界

- 全局检查优先报告最关键的 1 至 3 个断点，并引用目标、过程和评价中的具体原文。
- 不把个人教学偏好包装成一致性缺陷。
- 如果主要目标都有活动和评价证据，应明确说明整体一致，不强行生成修改。
- 写入建议必须保持教师原意，并只修改解决该断点所需的最小范围。
