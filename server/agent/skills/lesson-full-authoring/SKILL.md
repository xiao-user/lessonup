# 完整教案编写

## 读取与边界

1. 先确保掌握当前教案、教学情境和已经绑定的上游备课上下文；同一版本已有完整结果时复用，不重复读取。
2. 有课时蓝图时，继承单元目标、当前课时主要活动、学生可观察产出和达成证据。
3. 有前序课堂反馈时，把真实观察、练习缺口、错因或衔接问题落实到复习任务、过程支架或评价证据；没有反馈不得编造。
4. 守住当前课时容量与内容边界：承接前一课时产出，为后一课时保留明确起点，不把整篇、整章或后续课时全部压入本课。

## 成品标准

- 把本课真正处理的内容写入“重点知识”，复习与铺垫必须落实到具体活动、学生任务或评价证据，而不是标签。
- 目标、过程、评价、作业和板书互相对应，学生行为与产出可观察，内容能够直接用于课堂实施。
- 信息不足时基于现有可靠信息形成可用版本，只保留确实需要教师补充的真实学情条件。
- 不使用可替换到任意课题的通用表述，不写占位文案，不虚构教材事实、课堂反馈或班级情况。
- 完成后通过一次 `propose_document_patch` 提交整份教案确认；审批卡是唯一确认，不再口头询问。

## A4 阅读重点

- 读完本课目标、活动、可观察产出及可靠依据后，先辨认当前教案中相对更重要、真正支撑本课理解与实施的内容。重要性是突出显示的首要依据，不以内容是否藏在长段落里、是否容易被漏读为前提。判断与正文一次完成，直接写进 `replacement`，不先生成无标记教案再加工。
- 让重要内容优先在 A4 中清晰可辨：先按内容关系写清目标、活动与证据，选择自然段或清单即可承载的内容就不要再套小标题；确有多个需要区分的主题或阶段、标题能帮助教师定位时才使用 Markdown 标题。不要把每条目标或每个要点都包装成“标题＋解释”，也不要重复 A4 已有的栏目名。适合局部强调的重点，直接用系统约定的内联标记突出最短但语义完整的片段。教学概念、成立条件、关键行动、学生证据或易错判断只是判断线索，不是必须逐项标记的清单；是否容易被漏读只帮助选择呈现方式。
- 不规定标题数量、标记数量、密度、每栏必标或颜色与教学类别的固定对应；也不因已有标题就一律不标。重要内容应得到恰当突出，但不必每处都涂色；某段、某栏乃至整份教案可以没有小标题或笔迹标记。
- 不因标记而改写事实或添加空洞结论，不强调普通流程话、重复信息或整段正文。教师移除标记后，教案的教学内容仍应完整、可执行。
